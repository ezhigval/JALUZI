# v2 — план работ

Дата: 2026-08-26  
Статус: **не начат** (документация и бэклог)  
Предыдущая версия: **v1** закрыта на проде — см. [ROADMAP.md](../ROADMAP.md)

## Цель v2

Сделать прод не только «работающим», но и аккуратным: чистый код без AI-артефактов, быстрее страницы, выше доверие/конверсия, стабильная операционка (почта, заявки, бэкапы). Новых крупных фич без закрытия шага 1 не начинать.

---

## Шаг 1 (первый) — оптимизация кода, баги, следы ИИ

**Цель:** код и UI выглядят как осознанный продукт, а не черновик генерации.

### Убрать / нейтрализовать следы ИИ

- [ ] Эмодзи в UI/заголовках/логах Telegram, где они выглядят шаблонно (оставить только где осознанно нужны)
- [ ] Дефолтные «AI-look» паттерны на главной: purple gradient hero, emoji в Features/Repair, generic card shadows
- [ ] Комментарии вида «✅ ИСПРАВЛЕНИЕ», «=== ХЕЛПЕРЫ ===», избыточный шум в parser/фронте
- [ ] Placeholder-тексты и заглушки («Подробное описание скоро появится», везде `1500 ₽`)
- [ ] Мёртвый/дублирующий код, неиспользуемые скрипты, устаревшие JSON-миграционные ветки без нужды

### Баги и контрактные дыры

- [ ] В модалках parser-товаров не показывать `description` = URL Intersklad (fallback-шаблон)
- [ ] Стабильные string id товаров во всех клиентах (не `Number(id)` / `parseInt` там, где id hex)
- [ ] После `docker compose up web` не терять Caddy-прокси `/sitemap.xml` и `/catalog/p/*` (проверить образ vs hot-patch)
- [ ] Autodeploy: ветка на VM vs `AUTODEPLOY_BRANCH`; документированный/исправленный путь деплоя SEO-слоя API
- [ ] Прогнать `back` smoke/contract и починить падающие ассерты под актуальный контракт (`source`, `indexable`, string id)

### Оптимизация структуры кода

- [ ] Разнести page-scoped JS (каталог / works / map не грузить глобально без нужды)
- [ ] Единый serialize product (source/slug/path/indexable) без копипаста admin/public
- [ ] Упростить `AI_PROJECT_CONTEXT.md`: актуальный handoff + ссылка на ROADMAP (убрать устаревшее «JSON storage» как primary)
- [ ] Привести `.env.example` к одному блоку без дублей ключей

### Критерий готовности шага 1

- Главная/каталог визуально цельные, без «шаблонного AI» шума  
- Нет утечки Intersklad URL в пользовательских описаниях  
- Smoke/contract зелёные  
- Документы v1/v2 согласованы с продом

## Вне скоупа v2 (кандидат в v3)

## Как вести работу

1. Отдельная ветка на каждый шаг: `cursor/v2-step1-cleanup-781d`, …
2. База для PR: актуальная прод-линия (сейчас стек `search-engines-seo` → … → `main` по мере мержей)
3. После шага 1 — не смешивать большие визуальные редизайны с фичами шагов 3–5 в одном PR
4. Обновлять этот файл и [ROADMAP.md](../ROADMAP.md) при закрытии шага
