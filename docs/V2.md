### 5.5. Дополнительные способы продвижения (исследовать → применить)

По актуальным практикам 2025–2026 для локального бизнеса услуг ([обзор методов](https://vc.ru/seo/2937570-seo-prodvizhenie-sayta-v-2026-godu-klyuchevye-trendy-i-strategii), [локальное SEO](https://blog.nedigital.ru/2026/08/26/seo-optimizacziya-sajta-polnoe-rukovodstvo-po-vyhodu-v-top-yandeksa-i-google-v-2026-godu/)):

| Метод | Действие для Питер-Жалюзи |
| --- | --- |
| **E-E-A-T** | Фото реальных работ, гарантия, «замерщик приедет», кейсы до/после — не шаблонные тексты |
| **Поведенческие** | Удобная заявка, быстрый сайт, понятные цены — снижаем отказ с посадочных |
| **Контент-хабы** | 5–10 экспертных статей: «как выбрать жалюзи», «жалюзи vs шторы», «уход» — под инфо-кластеры Wordstat |
| **Яндекс Нейро / AI Overviews** | Структурированные FAQ, чёткие списки, JSON-LD — чтобы попадать в AI-ответы |
| **Региональные посадочные** | `/spb/<raion>/` под «жалюзи + район» без duplicate content |
| **Справочники** | Zoon, Yell, Flamp, локальные каталоги — единый NAP + ссылка на сайт |
| **Крауд-маркeting** | Ответы на форумах/картах/QA (осторожно, без спама) по теме жалюзи СПб |
| **Ссылочное** | Естественные ссылки: партнёры (окна, ремонт), локальные СМИ, кейсы — **без** бирж и массовой закупки |
| **Видео** | Короткие ролики монтажа/замера → RuTube/YouTube + embed на сайт (если есть ресурс) |
| **Telegram/VK канал** | Не прямой SEO-фактор, но брендовые запросы + трафик на посадочные |

- [ ] Пройти чек-лист методов выше; отметить в таблице семантики что внедрено
- [ ] Раз в месяц — ревизия Wordstat: новые хвосты, сезонность (весна/ремонт окон)
