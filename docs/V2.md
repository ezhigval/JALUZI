Сделать прод не только «работающим», но и аккуратным: чистый код без AI-артефактов, быстрее страницы, выше доверие/конверсия, стабильная операционка (почта, заявки, бэкапы), надёжность и SEO-продвижение. Новых крупных фич без закрытия шага 1 не начинать.

## Шаг 5 — SEO-продвижение и контент

**Цель:** системно раскрыть основные запросы по жалюзи в СПб/ЛО, выйти в органику Яндекса и Google и закрепить локальное присутствие. Не ограничиваться технической базой v1 — строим семантику, посадочные и внешние каналы.

### 5.1. Семантика через Яндекс Wordstat

- [ ] Завести рабочую таблицу семантики (`docs/seo/semantic-core.csv` или Google Sheet): запрос, частота `"!..."`, интент, кластер, целевая URL, статус
- [ ] Собрать **маркерные запросы** в Wordstat с регионом **Санкт-Петербург** (+ при необходимости Ленобласть):
  - коммерция: `жалюзи на заказ`, `жалюзи спб`, `купить жалюзи`, `жалюзи цена`, `замер жалюзи`
  - типы: `рулонные жалюзи`, `горизонтальные жалюзи`, `вертикальные жалюзи`, `день-ночь`, `плиссе`, `римские шторы`
  - услуги: `установка жалюзи`, `монтаж жалюзи`, `ремонт жалюзи`, `жалюзи на пластиковые окна`
  - гео: `жалюзи спб`, `жалюзи санкт-петербург`, `жалюзи <район>` (Приморский, Московский, Невский…)
- [ ] Расширить ядро по **левой колонке** Wordstat (хвосты) и **правой** («что ещё искали» — смежные темы)
- [ ] Очистить мусор: минус-слова (`бесплатно скачать`, `своими руками`, `фото`, `б/у`, конкуренты-бренды не нашей ниши)
- [ ] Снять **точную частотность** (`!"фраза"`) для приоритетных кластеров; отсечь нулевые/нерелевантные
- [ ] **Кластеризация** (Hard — одна посадочная на кластер; Soft — для инфо-статей): по пересечению TOP-10 выдачи или через Keys.so / Topvisor / Excel
- [ ] Разметить интенты: транзакционный / коммерческий / информационный / навигационный
- [ ] Составить **карту посадочных**: какой кластер → какая страница (существующая или новая)

### 5.2. Раскрытие по основным запросам (on-site)

- [ ] Для каждого **топ-кластера** — отдельная оптимизированная страница (не один каталог на всё):
  - категории: `/catalog/rolikovye`, `/catalog/gorizontalnye`, … (статический HTML + уникальный текст)
  - услуги: `/uslugi/zamer`, `/uslugi/ustanovka`, `/uslugi/remont`
  - гео: `/spb/` или `/spb/<raion>/` — уникальный текст под район (не копипаста)
- [ ] Title / H1 / description / первый абзац — под главный ключ кластера + гео «Санкт-Петербург»
- [ ] LSI-блоки: материалы, сроки, гарантия, бесплатный замер, монтаж, цены «от …»
- [ ] FAQ-блок на посадочных (вопросы из Wordstat / «People also ask») + разметка `FAQPage`
- [ ] 10–30 **manual-товаров** с нормальным текстом → `/catalog/p/<slug>` + sitemap (правило v1: parser без массовых SEO-страниц сохраняется)
- [ ] Внутренняя перелинковка: главная → категории → товары/услуги → заявка
- [ ] Alt-тексты и имена файлов у фото работ/товаров под запросы
- [ ] `sameAs` в JSON-LD (карты/соцсети), когда профили заведены
- [ ] BreadcrumbList + Service/Product schema на релевантных страницах

### 5.5. Дополнительные способы продвижения (исследовать → применить)

По актуальным практикам 2025–2026 для локального бизнеса услуг ([обзор методов](https://vc.ru/seo/2937570-seo-prodvizhenie-sayta-v-2026-godu-klyuchevye-trendy-i-strategii), [локальное SEO](https://blog.nedigital.ru/2026/08/26/seo-optimizacziya-sajta-polnoe-rukovodstvo-po-vyhodu-v-top-yandeksa-i-google-v-2026-godu/)):

| Метод | Действие для Питер-Жалюзи |
| --- | --- |
| **E-E-A-T** | Фото реальных работ, гарантия, «замерщик приедет», кейсы до/после — не шаблонные тексты |
| **Поведенческие** | Удобная заявка, быстрый сайт, понятные цены — снижаем отказ с посадочных |
| **Контент-хабы** | 5–10 экспертных статей: «как выбрать жалюзи», «жалюзи vs шторы», «уход» — под инфо-кластеры Wordstat |
| **Яндекс Нейро / AI Overviews** | Структурированные FAQ, чёткие списки, JSON-LD — чтобы попадать в AI-ответы |
| **Региональные посадочные** | `/spb/<raion>/` под «жалюзи + район» без duplicate content |
| **Справочники** | Zoon, Yell, Flamp, локальные каталоги — единый NAP + ссылка на сайт |
| **Крауд-маркeting** | Ответы на форумах/картах/QA (осторожно, без спама) по теме жалюзи СПб |
| **Ссылочное** | Естественные ссылки: партнёры (окна, ремонт), локальные СМИ, кейсы — **без** бирж и массовой закупки |
| **Видео** | Короткие ролики монтажа/замера → RuTube/YouTube + embed на сайт (если есть ресурс) |
| **Telegram/VK канал** | Не прямой SEO-фактор, но брендовые запросы + трафик на посадочные |

- [ ] Пройти чек-лист методов выше; отметить в таблице семантики что внедрено
- [ ] Раз в месяц — ревизия Wordstat: новые хвосты, сезонность (весна/ремонт окон)

## Как вести работу

2. База для PR: **`main`**
3. После шага 1 — не смешивать большие визуальные редизайны с фичами шагов 3–5 в одном PR
4. Обновлять этот файл и [ROADMAP.md](../ROADMAP.md) при закрытии шага
5. Секреты/токены — только в `.env` на VM, не в git; список для пользователя — в финальном handoff
